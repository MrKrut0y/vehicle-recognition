# Первый запуск YOLOv8 на Windows

Цель первого опыта — убедиться, что готовая нейросеть находит транспорт и может отслеживать его на видео. Городская камера и база данных на этом шаге не требуются. Команды ниже предназначены для PowerShell. На этом компьютере уже есть Python 3.14.5 и FFmpeg 8.1.1.

## 1. Открыть PowerShell и перейти в папку курсовой

Нажать клавишу Windows, набрать `PowerShell`, открыть приложение. Скопировать команду и нажать Enter:

```powershell
Set-Location -LiteralPath 'C:\Users\User\Desktop\курсовая'
```

В начале строки PowerShell должна появиться папка `курсовая`.

## 2. Создать отдельную среду Python

```powershell
py -m venv .venv
```

Команда создаст папку `.venv` с отдельным Python для проекта. Сообщение об успешном выполнении может не появиться — это нормально. Активировать среду не нужно: далее команды обращаются к ней напрямую.

## 3. Установить библиотеку для YOLO

```powershell
.\.venv\Scripts\python.exe -m pip install -U ultralytics
```

Нужен интернет. Установка скачает пакет и его зависимости; она может занять время. Успешное завершение — появление новой строки приглашения PowerShell без сообщения `ERROR`.

## 4. Проверить на готовом изображении

```powershell
.\.venv\Scripts\yolo.exe predict model=yolov8s.pt source=https://ultralytics.com/images/bus.jpg project=results name=first_test save=True
```

При первом запуске программа автоматически скачает готовые веса `yolov8s.pt` и тестовую фотографию. Затем создаст `results\first_test\bus.jpg`. Открыть эту фотографию в Проводнике. На автобусе должны появиться рамка, подпись класса и оценка уверенности; могут быть отмечены и люди. Если папка или имя файла отличаются, посмотреть путь после `Results saved to` в выводе команды.

## 5. Подготовить своё короткое видео

Положить в папку `C:\Users\User\Desktop\курсовая` видеоролик с именем `test.mp4`. Для первого опыта подойдёт запись длительностью примерно 20–30 секунд, где неподвижная камера или телефон снимает проезжающие машины. Важно, чтобы камера сама не двигалась. Если ролика пока нет, остановиться после шага 4.

## 6. Запустить отслеживание

```powershell
.\.venv\Scripts\yolo.exe track model=yolov8s.pt source=test.mp4 tracker=bytetrack.yaml project=results name=video_test save=True
```

Готовый ролик будет сохранён в `results\video_test` (точное имя файла указано в выводе команды). Проверить, что рамка следует за каждой машиной, а её временный ID сохраняется на последовательных кадрах. Первоначально модель может отмечать и другие объекты, например людей; фильтрацию только транспорта добавим после первого успешного опыта.

## Что означает каждая часть команды

- `yolo.exe` — программа для запуска моделей Ultralytics.
- `predict` — найти объекты на изображении или видео; `track` — дополнительно сопровождать их между кадрами.
- `model=yolov8s.pt` — использовать готовую модель YOLOv8s. Обучать её перед первым опытом не нужно.
- `source=...` — источник изображения или видео.
- `tracker=bytetrack.yaml` — выбрать алгоритм, связывающий обнаружения одного объекта на разных кадрах.
- `project=results name=... save=True` — сохранить результат в понятную папку.

Этот тест пока не читает государственные номера, не определяет цвет и не записывает данные в MySQL. После проверки обнаружения и отслеживания добавим эти части отдельно. Если возникнет ошибка, сохранить или скопировать её полный текст — по нему можно определить причину.
